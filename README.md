# Hora Pico

Juego multijugador sobre el control de una ciudad. Un jugador controla el
tráfico mientras que los otros dos controlan a los polícias y a la ciudad en sí
misma. ¿Caerá la ciudad en un caos automovilístico, o podrán nuestros héroes
manejar el caos?

Game Loop principal: una descripción detallada de lo que sería una sesión
promedio del juego.

Mecánicas: las características principales del juego

```
¿Cómo se mueve el jugador en el mundo?
¿Cómo interactúa el jugador con enemigos u otros personajes?
¿Hay combate? ¿Hay puzzles? ¿Hay narrativa?
Etc.
```

Género y público objetivo: Nos gustaría que el juego sea atractivo para un
público en general, pero nos enfocaríamos más en familias y grupos de amigos,
puesto que la idea es que se pueda jugar con gente que tienes confianza y no
necesariamente con un matchmaking tipo Valorant.
